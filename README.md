Lemonade
Application Android développée en Kotlin avec Jetpack Compose.

Fonctionnement
L'utilisateur suit 4 étapes :

 1-Sélectionner un citron
 2-Presser le citron 2 à 4 fois
3- Boire la limonade
4- Recommencer
Technologies
Kotlin
Jetpack Compose
Material 3
Android Studio
Installation
Ouvrir le projet dans Android Studio, synchroniser Gradle, puis lancer l'application sur un émulateur ou un appareil Android.

Objectif
Projet pédagogique pour apprendre la gestion de l'état, les composants Compose et les interactions utilisateur.
